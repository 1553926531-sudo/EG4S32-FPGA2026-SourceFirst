# FPGA 多媒体播放器用户操作手册

适用版本：2026-11-04 交付版，EG4S20 开发板，AN9134 HDMI 输出，1280×800 正式屏。

本手册按实际使用顺序介绍操作。屏幕上的 `K0` 对应开发板的 `KEY0`，其他编号同理。**普通点按指按下后松开；只有标明“长按”时才需要持续按住。**

## 1. 第一次使用：先完成这五步

1. 保持已经验证的 TF 卡、HDMI、扩展板和音频接线，打开正式屏，再给开发板供电。当前程序已写入配置 Flash，日常使用只需供电。
2. 等待 `READING TF CARD...`（正在读取存储卡）消失，进入 `FILES` 文件列表。刚开机不会自动播放视频，也不会播放声音。
3. 点按 **KEY1** 向上选择，点按 **KEY2** 向下选择；高亮行是将要打开的文件。
4. 点按 **KEY3** 打开高亮文件。视频播放画面和自身音轨；图片静音显示；歌曲显示纯色背景。
5. 随时点按 **KEY0** 返回文件列表。若只想看完整画面，点按 **KEY13** 隐藏全部信息，再按一次呼回。

启动时建议让八位拨码处于逻辑 `00000000` 的中性状态。拨码改变也可以直接选媒体，因此非中性拨码在上电稳定后可能触发相应功能。不同板卡的物理 ON 方向以丝印和实际屏幕状态为准。启动时尚未打开文件，KEY0/KEY13 会停留在列表页。

**数码管始终熄灭。状态以屏幕和 LED 为准。**

## 2. 找到板上的按键

使用标有 KEY0～KEY15 的 4×4 矩阵按键区。编号排布如下；按板上丝印确认编号，复位键和下载键不属于播放器按键。

```text
┌───────┬───────┬───────┬───────┐
│ KEY15 │ KEY14 │ KEY13 │ KEY12 │
├───────┼───────┼───────┼───────┤
│ KEY11 │ KEY10 │ KEY9  │ KEY8  │
├───────┼───────┼───────┼───────┤
│ KEY7  │ KEY6  │ KEY5  │ KEY4  │
├───────┼───────┼───────┼───────┤
│ KEY3  │ KEY2  │ KEY1  │ KEY0  │
└───────┴───────┴───────┴───────┘
```

最常用的操作组合：

| 想做什么 | 按键顺序 |
|---|---|
| 任意选一个文件 | KEY0 → KEY1/KEY2 找文件 → KEY3 打开 |
| 暂停或继续 | 播放页点按 KEY3 |
| 上一个或下一个文件 | 播放页点按 KEY1 / KEY2 |
| 定位到某个时间 | KEY4 → KEY14 选步长 → KEY1/KEY2 调时间 → KEY3 确认 |
| 取消刚才的定位 | 定位页点按 KEY4 |
| 一键静音或恢复 | 短按并松开 KEY15 |
| 调音量 | 长按 KEY15 约 0.5 秒 → KEY1 减 / KEY2 加 → KEY4 返回 |
| 隐藏所有遮挡 / 呼回界面 | KEY13 / 再按 KEY13 |
| 开关波形 / 歌词 | 播放页 KEY11 / KEY12 |
| 切换缩放 | 播放页 KEY10 |

同一时间只按一个键。系统抑制多个矩阵键同时按下的操作，避免误触；不需要使用组合键。

## 3. 四个页面分别怎么用

### 3.1 文件列表：FILES

列表包括卡内受支持的视频、图片和歌曲，按 **VIDEO → IMAGE → AUDIO** 分组。KEY1/KEY2 跨全库移动，不会被当前媒体类型限制；到头后从另一端继续。文件较多时列表自动翻动，高亮行始终跟随选择。

| 按键 | 列表中的作用 |
|---|---|
| KEY1 / KEY2 | 上一项 / 下一项；长按约 0.5 秒后连续移动，约每秒 12 次 |
| KEY3 | 打开高亮行，从头开始播放，并进入播放页 |
| KEY0 | 返回原播放页；第一次开机还未打开文件时留在列表 |
| KEY13 | 已有打开文件时退出列表并清屏；再按一次呼回信息 |
| KEY15 | 短按全局静音；长按打开音量页 |

浏览列表只移动光标，**按 KEY3 才会打开文件**。如果已有媒体在播放，打开列表会继续播放原来的歌曲或视频。LRC 是歌曲的歌词伴随文件，不作为独立项目列出。

列表名来自独立媒体的真实文件名，屏幕最多显示前 32 个 ASCII 字符；非 ASCII 字符显示 `?`。旧 PAK 的内部项目显示 `VIDEO_001`、`IMAGE_001`、`AUDIO_001` 这类兼容名称。独立文件由程序上电时实际枚举，不限于固定的演示文件。

### 3.2 播放页

顶部显示媒体类型、类别内编号、播放/暂停、画面参数、音量与开关状态；底部显示时间、进度条和操作提示。

| 按键 | 播放页中的作用 |
|---|---|
| KEY0 | 打开文件列表，光标回到当前文件 |
| KEY1 / KEY2 | 打开全库上一个 / 下一个文件；首尾循环 |
| KEY3 | 暂停 / 继续 |
| KEY4 | 打开按键定位页；尚无有效时长时不进入 |
| KEY5 | 轮换图片过渡模式 FX0 → FX1 → FX2 → FX3 → FX0 |
| KEY6 / KEY7 | 亮度减少 / 增加 |
| KEY8 / KEY9 | 对比度减少 / 增加 |
| KEY10 | 缩放 Z0 → Z1 → Z2 → Z3 → Z0 |
| KEY11 | 波形开 / 关 |
| KEY12 | 歌词或滚动标语开 / 关 |
| KEY13 | 清屏 / 呼回全部操作信息 |
| KEY14 | 当前媒体从头重载；保留此前播放或暂停状态 |
| KEY15 | 短按静音 / 恢复；长按音量页 |

普通播放页长按 KEY1/KEY2 不会连续换文件。KEY5～KEY12 只在播放页调整参数，在列表、定位或音量页保持无效。

### 3.3 按键定位页：SEEK PREVIEW

这是键控进度定位，进度条不需要指针设备。以跳到 `00:02:30` 为例：

1. 正在播放时点按 **KEY4**。出现 `SEEK PREVIEW - PLAYBACK IS HELD`，临时暂停并显示目标时间。
2. 点按 **KEY14** 选择步长。默认 10 秒，循环顺序为 **10 → 60 → 1 → 10 秒**，看 `STEP` 后的数值。
3. 点按或长按 **KEY1** 向前退、**KEY2** 向后进。先用 60/10 秒大步靠近，再用 1 秒精确调整。
4. 目标显示 `00:02:30` 后点按 **KEY3**，实际跳转并返回播放页。

KEY4 取消预览并保持原播放位置。KEY0 转到文件列表也会放弃本次预览。确认和取消都会恢复进入定位页前的播放/暂停状态；原来暂停就继续暂停。目标时间限制在文件范围内。

长按 KEY1/KEY2 约 0.5 秒后自动重复。定位主要用于歌曲和视频；图片没有可听音轨，可直接选图或暂停轮播。

### 3.4 音量页：VOLUME

**长按 KEY15 约 0.5 秒**打开音量页，松手后操作：

| 按键 | 音量页中的作用 |
|---|---|
| KEY1 | 音量降低一级，最低 0 |
| KEY2 | 音量提高一级，最高 16 |
| KEY3 | 静音 / 取消静音 |
| KEY4 | 回到进入音量页之前的页面 |
| 长按 KEY15 | 同样返回之前页面 |
| KEY0 | 转到文件列表 |
| KEY13 | 已打开文件时清屏进入播放页 |

共 **0～16 十七档**，默认 16；KEY1/KEY2 支持长按连续调整，调整会自动取消静音。`VOLUME 07 / 16` 表示第 7 档。`MUTED` 是主动静音，`SOUND ON` 是静音开关关闭；音量为 0 或媒体本身无音轨时，即使显示 SOUND ON 也没有声音。

KEY15 的短按在**松开时**生效；长按已打开音量页后，松开不会再次静音。音量是全局设置，换歌、换视频也保留，不改变文件原始 PCM 内容。重新上电恢复 16 且不静音。

## 4. 无遮挡观看、歌词和波形

**KEY13 一次隐藏顶部状态、底部提示、进度条、歌词和波形；再按一次恢复。**媒体继续播放，波形和歌词的开关设置保留。清屏时仍能用 KEY15 静音、KEY3 暂停或 KEY0 打开列表；这些操作会按功能显示相应信息。

播放歌曲时是纯色背景，不显示之前看过的图片；歌词和波形在屏幕中间的不同区域，不互相覆盖。KEY11 和 KEY12 是两个独立开关，支持只显示歌词、只显示波形、同时显示或都关闭。对应状态在顶部 `WAVE ON/OFF`、`SUB ON/OFF` 查看。

有配对歌词时，KEY12 控制当前歌词；长句分两行显示。没有歌词时，该键控制滚动英文标语。KEY13 清屏会把二者都隐藏，呼回后按原开关设置恢复。

图片始终没有伴奏，打开图片时不会播放其他歌曲。图片约每 5 秒在图片组内轮播；KEY3 暂停可停在当前图，继续后恢复轮播。视频使用自己的音轨；视频到结尾后循环，歌曲到结尾后循环当前歌曲，手动 KEY1/KEY2 可跨类型切换。

## 5. 缩放、画面调整与过渡

### 缩放：KEY10

| 显示 | 含义 | 使用场景 |
|---|---|---|
| Z0 | 保持比例适配 1280×800，空余部分留边 | 默认；希望看全图且不变形 |
| Z1 | 中心区域水平放大，两侧压缩 | 展示非线性缩放效果 |
| Z2 | 直接拉伸到整个屏幕 | 填满屏幕，可能改变物体比例 |
| Z3 | 原尺寸居中，超出屏幕部分裁掉 | 观察原图细节；小图居中 |

缩放切换会重载显示数据：歌曲/视频按当前整秒位置恢复，图片重载当前图，因此可能有短暂读取等待。缩放不会切换文件。要同时看完整图片并隐藏界面，选 Z0 后按 KEY13。

### 亮度与对比度

亮度用 KEY6 减、KEY7 加；对比度用 KEY8 减、KEY9 加。每次点按改变 16，边界饱和在 000～255；默认均为 128，顶部显示 `B128 C128`。参数不因换文件丢失，断电后回默认。

如果已经调到边界，想精确恢复 128：亮度连续点 KEY6 直到 `B000`，再点 KEY7 八次；对比度点 KEY8 到 `C000`，再点 KEY9 八次。每次点按后以屏幕数值为准。

### 过渡：KEY5

| 显示 | 含义 |
|---|---|
| FX0 | 关闭过渡，直接显示 |
| FX1 | 淡入 |
| FX2 | 擦除展开 |
| FX3 | 反向擦除，从右向左展开 |

KEY5 只改变过渡设置，不自动换文件；切图或重载时可观察效果。视频渲染固定使用无过渡，顶部 FX 仍表示保存的控制设置。关闭所有附加显示时，设为 WAVE OFF、SUB OFF、FX0，再按需要选择 Z0；清屏只隐藏图层，不重置设置。

## 6. 八位拨码怎么用

下表的 `bit0` 是输入逻辑的最低位，板上开关的 ON 方向不定义逻辑值。**拨码只在稳定变化时触发操作，停留在某个位置不会锁住按键。**例如拨码开过波形后，仍可按 KEY11 关闭。

| 拨码位 | 变化后执行的动作 |
|---|---|
| bit0 | 波形开关翻转一次 |
| bit1 | 歌词/标语开关翻转一次 |
| bit2 | 已打开文件时，界面开关翻转并回播放页 |
| bit3 | FX0 与 FX1 切换；当前为 FX2/FX3 时回到 FX0 |
| bit5:bit4 | `00=Z0`、`01=Z1`、`10=Z2`、`11=Z3` |
| bit7:bit6 | `00` 不切文件；`01` 打开第一段视频；`10` 打开第一张图片；`11` 打开第一首歌；该类为空则不打开 |

当前波形和歌词状态以顶部 ON/OFF 与 LED 为准。再次触发同一分类时，先拨回 `00`，再选择目标分类。

## 7. LED 和数码管

| LED 位 | 表示什么 |
|---|---|
| LED0 | 从头重载或确认定位时的短脉冲，持续很短 |
| LED1 | 暂停；定位预览和启动未打开文件时也属于暂停 |
| LED2 | 波形设置开启 |
| LED3 | 歌词/标语设置开启 |
| LED4 | 界面显示设置开启 |
| LED5 | 当前缩放不是 Z0 |
| LED6 | 保存的过渡设置不是 FX0 |
| LED7 | 当前处于列表、定位或音量页 |

LED 表示控制逻辑状态，实际亮灭电平以板上接法为准。清屏时 LED2/LED3 可以仍表示开启，但画面上的歌词和波形已隐藏。数码管不显示文件号、参数或任何其他内容，所有位保持熄灭。

## 9. 文件与存储卡规则

程序上电扫描 FAT32/exFAT 文件系统，支持子目录及碎片；不依赖为演示卡写死的扇区位置。支持 MBR 或裸卷、512 字节逻辑扇区，不支持 GPT、NTFS、FAT16。读取期间保持卡在位；更换卡后重新上电。

| 类型 | 必须满足的编码 |
|---|---|
| BMP | 24/32 位 BI_RGB 未压缩，宽和高各 1～2048，支持正/倒向行序 |
| WAV | RIFF PCM，48 kHz、16 位、双声道，最多 172,800,000 个双声道样本帧 |
| LRC | 与 WAV 同目录、同主文件名；可打印 ASCII，最多 1 MiB、4096 句、每句 78 字符；时间严格递增、分钟小于 60，且在曲目内 |
| TFV | 本工程 TFM3 单视频容器，图像帧与 PCM 已转码；普通 MP4/AVI 改扩展名不能使用 |
| PAK | 保留的 TFM3 素材包兼容方式；存在支持的独立媒体时优先使用独立媒体 |

视频、图片、歌曲各最多 128 个，歌词最多 127 个，最多枚举 64 个目录。分类内按卡上目录枚举顺序排列；准备指定次序的新卡时，按顺序复制并在板上核对，目录物理顺序不等同于字母排序。

单个独立文件可单独增删，不要求重新构建 FPGA。文件扩展名只是类别标记，实际编码也必须符合上表。通用转换工具为源码目录中的 `tools/media_convert.py`；独立双语文件 `docs/媒体格式规范与转换指南_Media_Format_Specification.md` 说明转换步骤、全部容器字段、编码和校验。构建和烧录步骤见该目录 README。

## 10. 常见情况与恢复

| 情况 | 先检查什么 / 怎么恢复 |
|---|---|
| 刚开机没有声音 | 列表启动时不播放声音；用 KEY3 打开歌曲或视频 |
| 播放图片没有声音 | 图片播放为静音 |
| 播放歌曲没有图片 | 歌曲使用独立纯色背景 |
| 看不见歌词或波形 | 先 KEY13 呼回界面；再核对 SUB/WAVE 开关；歌词还需匹配 LRC |
| 不知道当前在哪个页面 | KEY0 进入列表；有文件已打开时再 KEY0 返回播放页 |
| 声音消失 | 看 MUTED、VOL，短按 KEY15 解除静音；长按进入音量页并用 KEY2 提高，再查屏幕音量 |
| 图不完整 | KEY10 选 Z0；KEY13 清屏；Z3 会裁剪超出屏幕的部分 |
| 想只停留看一张图 | 图片播放页 KEY3 暂停，KEY13 清屏 |
| 定位时声音暂停 | 正常，KEY3 确认或 KEY4 取消后按原暂停状态恢复 |
| FILE ERROR 54 | BMP 尺寸、像素布局或编码不合要求 |
| FILE ERROR 55 / 56 | WAV 容器结构错误 / PCM 编码参数不支持 |
| FILE ERROR 57 / 58 | LRC 配对或大小错误 / 歌词文本或时间错误 |
| 文件报错后想继续用 | KEY0 选另一文件；保留错误代码和文件名供定位 |
| 一直 READING 或无文件 | 检查卡是否就位、文件系统和真实媒体编码，断电后再处理卡 |
| INVALID、黑屏或花屏持续 | 检查供电、HDMI、卡与位流版本，记录文件名、按键顺序和现象 |
| 断电后不是这一版 | 核对是否完成配置 Flash 写入和校验；仅 SRAM 下载不具断电保留能力 |
